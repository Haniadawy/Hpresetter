# CH341 EEPROM Writer (Android)

تطبيق أندرويد يتصل بمبرمجة **CH341A** عبر USB-OTG ويتعامل مع ايبروم **24C256** (I2C).

## المميزات (الإصدار الأول)
- رسالة حالة: **المبرمجة متصلة / غير متصلة** + حالة الايبروم (ACK على العنوان 0xA0).
- زر **كتابة 0xFF** على كامل الايبروم ما عدا أول صفوف (قابل للتعديل: 5 أو 6 صفوف = 80 أو 96 بايت).
- زر **قراءة أول 64 بايت** لعرضها Hex قبل وبعد العملية.
- زر **تحقق** يقرأ كل الشريحة ويتأكد أن القيم = FF.
- شريط تقدم للعملية.

## التوصيل
| CH341A | 24C256 |
|---|---|
| SDA (D) | SDA - رجل 5 |
| SCL (CK) | SCL - رجل 6 |
| VCC 5V/3.3V | VCC - رجل 8 |
| GND | GND - رجل 4 + A0,A1,A2 + WP |

> WP يجب أن يكون على GND وإلا لن تتم الكتابة.
> إذا كانت أرجل العناوين A0/A1/A2 مرفوعة، غيّر `devAddr` في `Eeprom24c256` (0xA0 … 0xAE).

## البناء على GitHub
1. أنشئ Repository جديد (مثلاً `ch341-eeprom-android`).
2. ارفع كل الملفات كما هي (مع مجلد `.github`).
3. من تبويب **Actions** شغّل *Build APK* أو انتظر البناء التلقائي بعد أي Push.
4. حمّل الـ APK من **Artifacts → app-debug-apk**.

## ملاحظات فنية
- بروتوكول CH341 المستخدم: `0xAA` stream، `0x74` START، `0x75` STOP، `0x80|n` إرسال، `0xC0|n` استقبال.
- الكتابة تتم على مقاطع 16 بايت مع تأخير 6ms (زمن دورة الكتابة الداخلية للشريحة).
- الوقت التقريبي لمسح 32KB ≈ 15-25 ثانية.
- الهاتف يجب أن يدعم **USB Host (OTG)**، ويفضل استخدام كابل OTG مع مصدر طاقة إذا كانت المبرمجة تسحب تيار عالي.

## الخطوات القادمة المقترحة
- قراءة كامل الشريحة وحفظها كملف `.bin` (نسخة احتياطية قبل الكتابة).
- كتابة ملف `.bin` جاهز.
- دعم أنواع أخرى (24C02 / 24C04 / 24C16 بعنونة 8 بت، و 93Cxx).
